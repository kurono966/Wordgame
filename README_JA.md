# ワードゲーム

スロットカードと手札のカードを使って単語を構築し、敵にダメージを与えながら自身のHPを守る戦略的ワードビルディングゲームです。

## ゲーム概要

スロットと手札のカードを使って有効な英語の単語を作成します。各カードには文字とダメージ値があります。プラスのダメージは敵に与え、マイナスのダメージ（夜のペナルティ）は自分へのダメージになります。10ターンの間にHPを管理しながら、多くの敵を倒しましょう。評価は総与ダメージと撃破数で行います。

## HPと敵

- **プレイヤーのHP**: 50（緑のHPバーで表示）
- **敵**: 敵は1体ずつ出現します（赤のHPバーで表示）。最初の敵はHP30です。
- **敵の名前**: 辞書からランダムに選択されます（英字のみ・3〜9文字）。
- **共有札**: スロット3列は現在の敵の名前の文字を使用して構成され（9枚の並び順はランダム）、余りは共有カードプールからランダムに抽選します。共有札はプレイヤーの20枚デッキとは別で、山札・墓地には入りません。
- **プラスのダメージ**: 現在の敵のHPを減らします。敵のHPが0になるとステージクリアして次のステージへ進みます。超過ダメージは無効となり、次の敵には引き継がれません。
- **ステージ**: 各ステージに敵が1体出現します。倒すと次のステージへ進み、より強い敵（最大HP+15）が出現して**カードがリセット**されます（手札7枚を全て捨てて引き直し、共有スロットは新しい敵の名前の文字で再構成され、3列のリールが回転して新しいカードが表示されます）。
- **マイナスのダメージ**: 自分のHPを減らします（0未満にはなりません）。HPが0になるとゲームオーバー（DEFEAT）です。
- **結果**: 10ターンでゲーム終了（COMPLETE）、到達ステージ・総与ダメージ・撃破数で評価されます。

## ゲームルール

### 基本設定
- **3つのスロットリール**: 各スロットには3枚のカードが含まれ、回転できます
- **7枚の手札**: 文字を埋めるために使用できるカード
- **カードプールとデッキ**: プールは99種類。各ゲームでプールからランダムに20枚を選んでデッキを構成します。山札が無くなったら墓地をシャッフルして山札に戻します
- **プレイヤーHP**: 50 / **敵のHP**: ステージ1は30（ステージ毎に+15）
- **ステージ**: 敵を倒すと次のステージへ進み、手札と共有スロットがリセットされます
- **10ターン**: 10ターン後にゲーム終了
- **敵と共有札**: 各敵の名前は辞書からランダムに選ばれます（英字3〜9文字）。スロットの共有札はその名前の文字で構成され（足りない分はランダム抽選）、プレイヤーのデッキとは別扱いです
- **辞書**: 有効な英語の単語のみが受け付けられます

### 遊び方
1. スロット（★ ACTIVEと表示）または手札からカードをクリックまたはドラッグしてワークベンチに追加
2. カードを配置して有効な単語を作成
3. SUBMIT WORDをクリックして単語でダメージを与える
4. 使用した共有札は消費され、そのスロットは次のカードに回転します
5. 使用された手札は破棄され、デッキから補充されます
6. 敵のHPを0にしてステージをクリアすると次のステージへ進み、手札は引き直され、3列のリールが回転して新しい敵の共有札が表示されます

### 提出プレビュー（被ダメージの予告）
ボタンの上には、**単語を作っている途中でも**、その提交で受けるダメージが表示されます。ワークベンチにカードを追加・削除するたびに自動更新されます。

- 実際に提出したときと**同じ割当**で計算するため、表示の数値と実際の結果は必ず一致します
- 敵へのダメージ、その単語が得るシールド・回復、夜のペナルティ、最終的な「失うHP → 後のHP」を表示します
- **提出すると共有札が回転する**ため、夜のペナルティは「回転した後のNEXTカード」を読んで予告します。スロットを使うと予告が変わる場合があり、回転するリール数が表示されます
- 危険度で色を付けます：緑=被ダメージなし、黄=HPを失う、赤=**この提出で敗北する（LETHAL）**
- 単語として不正な場合は「提出は拒否される」と表示されます

### スロットの回転
- 単語で使用したスロットのみが回転します。使用した★ACTIVEのカードは消費され、リールが回転してNEXTのカードがACTIVEになります
- ワークベンチに置いたカードが必ず消費されます（使用した共有札が手札に勝手に差し替えられることはありません）ので、使用したリールは必ず回転します
- ステージクリア時は3列すべてのリールが回転し、新しい敵の共有札が表示されます

### 昼/夜フェーズ
ゲームは各ターンごとに昼と夜のフェーズを交互に切り替えます：

**昼フェーズ**: 被ダメージなし
**夜フェーズ**: ターン開始時に、すべてのスロットの次のカードのダメージ合計分のダメージを自分が受ける

### カードの色と倍率
各カードには色属性があります（赤、青、緑、黄、またはワイルドカード用の金）。ダメージ倍率は単語内で一緒に使った**赤いカードのみ**に適用されます：

- **赤2枚**: 2倍
- **赤3枚**: 4倍
- **赤4枚**: 8倍
- 計算式: 2^(n-1) （nは赤カードの枚数）

青・緑・黄の同色複数枚はダメージ倍率になりません（それぞれの色は特性を発動させます。参照: カラー特性）。

単語の倍率は以下に適用されます：
- 単語で与えるダメージ

夜フェーズの自己ダメージは、より大きな色倍率を使用します：
- **同色2枚**: 10倍のダメージ
- **同色3枚**: 100倍のダメージ
- 計算式: 10^(n-1) （nは同色の次のスロットカードの数）

### カラー特性
有効な単語で使ったカードの色が特性を発動します（共有札も同様にカウントされます）：

- **赤 — 攻撃倍率**: 敵へのダメージはベース合計基準で `base × 2^(赤枚数-1)`（赤1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍）。追加ボーナスは乗りません。
- **青 — シールド**: シールド獲得量はベース合計基準で `base × 2^(青枚数-1)`（上限なし）。シールドはHPに被害が及ぶ前にダメージを吸収します（夜の自己ダメージ・負の単語ダメージ）。
- **緑 — 回復**: 回復量はベース合計基準で `base × 2^(緑枚数-1)`（最大HPまで）。
- **黄 — 操作ポイント（OP）**: OP はベース合計基準で `base × 2^(黄枚数-1)`（黄1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍）。OPはスコアではなく通貨で、ダメージでは消費されずリセットもされません。**1 OPでワークベンチのカードを左右に1つ移動できます**（ターンは消費しません）。**★スペシャルはそのカードのダメージ数値のOPを支払って発動します**（8ダメージ=8 OP、10ダメージ=10 OP）。OPが足りない場合は発動できません。

特性の基準は**プラスのベース合計**です（負の単語では特性値は発生しません）。各特性の適用は1回のみです。

### ワイルドカード
- **「?」カード**は任意の文字を表すことができます
- ダメージは0ですが、難しい単語を完成させるのに役立ちます
- プールには9枚のワイルドカードが含まれ、ランダムな20枚のデッキに入る枚数はゲーム毎に変わります
- 各ワイルドカードは通常のカードと同様に色属性（赤、青、緑、黄）を持っています
- ワイルドカードの色を他の同色カードと合わせることで倍率を上げられます
- 文字は金色で表示され、枠線でその色を確認できます

### ダメージ値
各文字はレア度に基づいてダメージ値を持っています：
- 1ダメージ: E, A, I, O, N, R, T, L, S, U（一般的）
- 2ダメージ: D, G
- 3ダメージ: B, C, M, P
- 4ダメージ: F, H, V, W, Y
- 5ダメージ: K
- 8ダメージ: J, X
- 10ダメージ: Q, Z
- 0ダメージ: ?（ワイルドカード）

### 計算式
ゲーム内の **FORMULAS** ボタンを押すと計算式パネルが開きます。以下の全計算式がコード内の実際の数値付きで表示され、直前に提出した単語の内訳も確認できます。

**敵へのダメージ（プラスのダメージ）**
- `base`（基本ダメージ）= 単語に置いた全カードのダメージ合計（ベース合計）
- `赤倍率` = 2 ^ (赤カード枚数 - 1) → 赤1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍
- `最終ダメージ` = base × 赤倍率。青・緑・黄の同色複数枚はダメージを倍加しません
- 敵の残りHPを超えたダメージは切り捨て（次の敵に引き継がれません）

**青のシールド（自分）**
- `シールド` = base × 2 ^ (青カード枚数 - 1) → 青1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍（上限なし）
- `吸収量` = min(シールド, 被ダメージ)。夜の自己ダメージと負の単語ダメージをHPより先に吸収します

**緑の回復（自分）**
- `回復` = base × 2 ^ (緑カード枚数 - 1) → 緑1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍（最大HP50まで）

**黄の操作ポイント（OP・自分）**
- `OP` = base × 2 ^ (黄カード枚数 - 1) → 黄1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍
- 1 OP = ワークベンチのカードを1つ左右に1マス移動。OPは蓄積し、ダメージで消費されません

**カードのコスト — ダメージ数値がそのままコスト（OPで支付）**
- 全カードの `コスト` = カードに印字されたダメージ値
- ★スペシャル（8ダメージ以上のカード）は、そのダメージ値のOPを支払って発動（8ダメージ=8 OP、10ダメージ=10 OP）
- 発動するとそのカードと同じ色の手札がすべて捨てられ、新しいカードを引きます（ターンは消費しません）
- OPが足りない場合は発動が拒否され、カードもOPも消費されません

**夜の自己ダメージ**
- `ペナルティ` = (3スロットのNEXTカードのダメージ合計) × 10 ^ (同色枚数 - 1) → 同色2枚=10倍、3枚=100倍、4枚=1000倍
- 青のシールドが先に吸収し、残りがHPに適用されます

**その他**
- 負の単語では特性値は発生しません（特性はプラスのベース合計を使用）
- 黄: 操作ポイント（OP）を獲得（前述） / ワイルドカード「?」: ダメージ0・任意の文字・色はそのまま
- 敵HP: ステージ1は30、ステージ毎に最大HP+15 / プレイヤーHP0で敗北、10ターンでCOMPLETE

### 勝利戦略のヒント
1. **先を見越す**: スロットの次のカードを見て、将来の被ダメージを予測（計算式の「夜の自己ダメージ」参照）
2. **色のマッチング**: 倍率のために同じ色のカードを使用
3. **スロットの管理**: どのスロットを使用するか検討（使用したスロットは次のカードに回転します）
4. **ワイルドカード**: 難しい文字の組み合わせのためにワイルドカードを残す
5. **HPを守る**: 夜フェーズで大きな被ダメージを受けると敗北します
6. **ステージとカードリセット**: ステージクリア時は手札とスロットが入れ替わるため、とどめを刺す前に大事なカードを使っておきましょう

### 操作方法
- **カードをクリック**: ワークベンチに追加
- **カードをドラッグ**: ワークベンチにドラッグ＆ドロップ
- **ワークベンチのカードをクリック**: ワークベンチから削除
- **手札の★カードを長押し/右クリック**: カードのダメージ数値のOPを支払ってスペシャルを発動
- **CLEAR**: ワークベンチからすべてのカードを削除
- **SUBMIT WORD**: 単語をスコアリングのために提出
- **FORMULAS**: 計算式と直前の単語の内訳の表示/非表示を切り替え
- **OPゲージ**（HPバーの右の金色の枠）: 所持OP・それでできるカード移動回数（`= N MOVES`）・バーを常時表示し、獲得時は数字がポップして `+N OP` が浮かびます。パネルにカーソルを合わせると詳細ルールのツールチップが表示されます
