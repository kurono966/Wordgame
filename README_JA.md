# ワードゲーム

スロットカードと手札のカードを使って単語を構築し、敵にダメージを与えながら自身のHPを守る戦略的ワードビルディングゲームです。

## ゲーム概要

スロットと手札のカードを使って有効な英語の単語を作成します。各カードには文字とダメージ値があります。プラスのダメージは敵に与え、マイナスのダメージ（夜のペナルティ）は自分へのダメージになります。10ターンの間にHPを管理しながら、多くの敵を倒しましょう。評価は総与ダメージと撃破数で行います。

## HPと敵

- **プレイヤーのHP**: 50（緑のHPバーで表示）
- **敵**: 敵は1体ずつ出現します（赤のHPバーで表示）。最初の敵はHP30です。
- **敵の名前**: 辞書からランダムに選択されます（英字のみ・3〜9文字）。
- **共有札**: スロット3列は現在の敵の名前の文字を使用して構成され（9枚の並び順はランダム）、余りは共有カードプールからランダムに抽選します。共有札はプレイヤーの20枚デッキとは別で、山札・墓地には入りません。
- **プラスのダメージ**: 現在の敵のHPを減らします。敵のHPが0になるとステージクリアして次のステージへ進みます。超過ダメージは無効となり、次の敵には引き継がれません。
- **ステージ**: 各ステージに敵が1体出現します。倒すと次のステージへ進み、より強い敵（最大HP+15）が出現して**カードがリセット**されます（手札7枚を全て捨てて引き直し、共有スロットは新しい敵の名前の文字で再構成され、3列のリールが回転して新しいカードが表示されます）。
- **敵を倒すたびに三択の報酬**: 次の戦いの前に**3つの中から1つ**を選べます。デッキの厚みを自分の都合で変えられる設計です。

**敵スキル（共有札9枚のうち1枚）**
敵は自分の名前の文字で構成され、**そのうち1文字に敵スキルが結ばれます**。その文字のカードは共有スロット9枚のうち**ちょうど1枚**として配られ、**そのカードがスロット下段にある状態で「夜」になると発動**します。

- **文字を並べても発動しません。発動するのは「位置」です。** その文字を単語に使っても、そのカードをクリックしても、下段にない限り何も起きません
- 発動するのは**夜だけ**です。昼のターンには決して発動しません
- スキルカードはHPバーの下（`STAGE … | DANGER: [B]AEGIS — slot 2 BOTTOM` / `— safe`）に表示され、危険なら**オレンジの枠＋⚠マーク**で示されます。現在の発動判定（`BOTTOM`か`safe`か）が常に見えます
- **カードが1枚だけ**なので、危険の所在は常に1箇所だけです。9枚のうち残り8枚は安全です
- **夜までに下段から退避させればよい。** スロット下の**SPINボタン**（1ターン目は1 OP、2回目は10 OP、3回目は100 OP。1ターン3回まで）を押すか、**そのスロットを使う単語を提出**して回転させれば、カードを追い出せます。カードの位置を操作するのが夜を凌ぐ側の仕事になります
- **初期デッキは固定の20枚**です。色ごとに5枚ずつ、必ず同じ構成で開始します。これらは**プレイヤー用カード**であり、敵がどの文字に技能を割り当てたであっても、スキルカード（共有スロット上の1枚）とは別のカードなのでデッキは影響を受けません。なお **Q と X はカードを配れない文字**（報酬専用）のため、スキル文字として選ばれません
- **倒し撃ちは先に命中します。** その単語で敵を倒したときはスキルは発動しません（戦闘が終わる前に敵は返撃できません）
- **「?」ワイルドカードはスキルカードになり得ません。** ワイルドカードは敵の文字ではないためです
- スキルはステージごとに強化され、上限を設けてあります（終盤でも破綻しない範囲）

| スキル | 効果 |
|---|---|
| **AEGIS** | 敵がシールドを貼り、**敵のHPより先に**ダメージを吸収します（`[ENEMY SHIELD n]` と表示） |
| **HAND DOWN** | 手札の枚数が減ります（最低3枚）。余ったカードは墓地に行くので**カードが消えることはありません** |
| **DRAIN** | 敵が操作ポイント（OP）を吸収します（0未満にはなりません） |
| **NIGHTMARE** | 夜のペナルティの**基礎値**に加算されます（同色の倍率はそのまま掛かります） |
| **REGROWTH** | 敵が自分のHPを回復します（最大HPは超えません） |

**ステージクリア後に効果の残存はありません。** 敵が倒された瞬間、そのシールド・夜の税・縮小された手札はすべて解除され、手札は7枚まで引き直されます。次の敵はクリーンな状態から始まります。**引き継がれるのは既に受けたダメージだけ**です。これは回復で戻せるHPだからです。

**報酬の一覧**

| 報酬 | 効果 |
|---|---|
| **★ SPECIAL CARD** | **表示される特定の★スペシャル**を1枚デッキに追加（能力とOPコストが明記されます） |
| **BURN A CARD** | **あなたが選びます**：デッキ全体のカードが一覧表示され、クリックした1枚が削除されます |
| **VITALITY** (HP) | HPを回復（最大値の25%、最低10） |
| **BARRIER** (SH) | シールドを8獲得 |
| **INSIGHT** (OP) | 操作ポイントを5獲得 |
| **IRON WILL** (MAX) | 最大HPが5上昇（現在HPも同量回復） |
| **CARD DRAW** (DR) | デッキから1枚引いて手札に追加 |
| **WILDCARDS** (???) | ワイルドカード（`?`）を**3枚**デッキに追加 |

- **カード報酬は★スペシャル以外は出しません。** ただの文字カードは、最初から持っている固定20枚と何も変わらない使い捨てで、デッキを薄めるだけになります。選択肢として意味を持つのは**「どの能力を受け取るか」**です。カードは事前に抽選されそのまま表示されます（提示されたカードと実際に獲得されるカードは必ず同一）
- **WILDCARDS は 0 ダメージの `?` を3枚**あげます。各カードは色を持っているため、その色の倍率には数えられます。得られるのは「足りない文字を1枚で埋める」という選択肢です
- **BURN A CARD はその逆で、こちらは何も決められません**。選ぶと**デッキ全体（山札・手札・使用済みの墓地）が一覧表示**され、各カードには色と「どの山札か」のタグが付きます。**クリックした1枚だけが削除**されます
- 一覧画面の **★スペシャル**は能力とコストが明記されるので、中身を知らずに焼き捨てることがありません
- 一覧画面で **BACK TO REWARDS** を押すと取り消せます。カードをクリックするまで報酬は消費されず、戻ると3択は**そのまま同じ内容**で表示されます
- **必ず3択**になり、うち最低1つはデッキ変更（追加/削除）です（デッキが上限/下限に達している場合はその片方のみ）
- デッキの**最小5枚・最大40枚**に制限されます。山札が尽きると墓地とシャッフルして再循環するため、枚数が大きく変わってもドローは破綻しません
- **敗北時と最終ターン（10ターン目）には報酬は出ません**（次の戦いがないため）
- **マイナスのダメージ**: 自分のHPを減らします（0未満にはなりません）。HPが0になるとゲームオーバー（DEFEAT）です。
- **結果**: 10ターンでゲーム終了（COMPLETE）、到達ステージ・総与ダメージ・撃破数で評価されます。

## ゲームルール

### 基本設定
- **3つのスロットリール**: 各スロットには3枚のカードが含まれ、回転できます
- **7枚の手札**: 文字を埋めるために使用できるカード
- **カードプールとデッキ**: プールは99種類。各ゲームでプールからランダムに20枚を選んでデッキを構成します。山札が無くなったら墓地をシャッフルして山札に戻します
- **プレイヤーHP**: 50 / **敵のHP**: ステージ1は30（ステージ毎に+15）
- **ステージ**: 敵を倒すと次のステージへ進み、手札と共有スロットがリセットされます
- **10ターン**: 10ターン後にゲーム終了
- **敵と共有札**: 各敵の名前は辞書からランダムに選ばれます（英字3〜9文字）。スロットの共有札はその名前の文字で構成され（足りない分はランダム抽選）、プレイヤーのデッキとは別扱いです
- **辞書**: 有効な英語の単語のみが受け付けられます。単語リストは **`data/word_dictionary.json`**（416,292語）と日本語の訳テーブルをまとめて保持しています。`tools/build_word_json.py` が `data/dictionary.txt` から生成します。JSON がない／壊れている場合は `data/dictionary.txt` を直接読み込むので、起動に失敗することはありません

### 遊び方
1. スロット（★ ACTIVEと表示）または手札からカードをクリックまたはドラッグしてワークベンチに追加
2. カードを配置して有効な単語を作成（**ドラッグでは入れたい隙間に向けてください**。クリックは末尾に追加されます）
3. SUBMIT WORDをクリックして単語でダメージを与える
4. 使用した共有札は消費され、そのスロットは次のカードに回転します
5. 使用された手札は破棄され、デッキから補充されます
6. 敵のHPを0にしてステージをクリアすると次のステージへ進み、手札は引き直され、3列のリールが回転して新しい敵の共有札が表示されます

### 初期デッキ（固定20枚）
毎ゲーム、**この20枚ちょうど**で開始します。色ごとに5枚ずつ、同じ構成です。これらは**プレイヤー用カード**であり、敵がどの文字に技能を割り当てたであっても、スキルカード（共有スロット上の1枚）とは別のカードなのでデッキは影響を受けません。

| 色 | 効果 | カード |
|---|---|---|
| 🔴 **RED** | ダメージ倍率 | A / T / E / M / S |
| 🔵 **BLUE** | シールド | E / N / L / P / I |
| 🟢 **GREEN** | 回復 | A / R / D / G / O |
| 🟡 **YELLOW** | オペレーションポイント | T / C / B / Y / E |

以降は報酬での追加・削除があるため、デッキは出発点であり固定されているわけではありません。

### デッキの確認
- **CARD PILES**（下のボタン）は戦闘中いつでもデッキ確認を開けます
- **山札（DRAW PILE）・手札（HAND）・墓地（GRAVEYARD）** の3つに分けて表示し、**すべてのカードを1枚ずつ**描画します。まだ引いていないカードが何かが全て分かります
- 山札は**アルファベット順に並べて**表示するため、中身は確認できますが、実際に引く順番は分かりません
- 報酬選択画面では **VIEW MY DECK**（または **D** キー）で同じ画面を開けます。**報酬の選択肢はその下に残ったまま**なので、「このカードを取る」か「今のデッキを薄くする」かを離れずに比較できます

### 提出プレビュー（被ダメージの予告）
ボタンの上には、**単語を作っている途中でも**、その提交で受けるダメージが表示されます。ワークベンチにカードを追加・削除するたびに自動更新されます。

- 実際に提出したときと**同じ割当**で計算するため、表示の数値と実際の結果は必ず一致します
- 敵へのダメージ、その単語が得るシールド・回復、夜のペナルティ、最終的な「失うHP → 後のHP」を表示します
- **提出すると共有札が回転する**ため、夜のペナルティは「回転した後のNEXTカード」を読んで予告します。スロットを使うと予告が変わる場合があり、回転するリール数が表示されます
- 危険度で色を付けます：緑=被ダメージなし、黄=HPを失う、赤=**この提出で敗北する（LETHAL）**
- 単語として不正な場合は「提出は拒否される」と表示されます

### 単語の意味（同梱 glossary → Jisho API）
ワークベンチに有効な単語を置いている間、被ダメージ予告の上に**英語 → 日本語**の訳を表示します。Lookup は2段階です：

1. **`data/word_dictionary.json`**（同梱 glossary） — 即座に表示され、ネットワーク不要で、Web エクスポートでも動作します。和訳のある単語だけを記載しています（空のエントリは無く、未収録の単語は手順2に回ります）。和訳のある単語は **`translations` にだけ記載し、`words` には入れない**（両セクションは重複しない）ので、ゲームは両者の和集合を使用可能な単語として扱います
2. **Jisho**（jisho.org） — 同梱 glossary に無い単語のためのフォールバックです（リクエストと結果の選び方は下記の通り）

> 現在 glossary には **98,813語**（アルバドット列のほぼ全体）が入っています。先頭3000語は和訳が確定しているものには実際の和訳を付与し（`data/head3000.json`）、確定的な和訳が無いものはカテゴリタグで示しています（この範囲は化学のtrivial名・ラテン語の分類群名・地名／人名が中心和）。したがって `CAT`・`AND`・`THE`・`ABBACY`・`ACCUMULATE`・`ACETYLENE` などが即座にオフラインで和訳され、それ以外は Jisho に回ります。単語を追加するにはソース表に1行足して `build_word_json.py` を再実行するだけで、コード変更は不要です。このスクリプトは既存 `word_dictionary.json` を**消 않고統合**します。

```
GOAT   →   山羊 (やぎ)  Noun
				goat
```

- 見出し語は金色、英訳は淡い青で表示されます（Godot 4 の `Label` は BBCode を描画できないため、マークアップを使わずラベルを分けています）
- Jisho の検索は**英訳に対する全文検索**のため、無関係な語も混ざります（「goat」で検索すると未「the Ram; the Goat」や、山羊でもなく他の語が先頭に来ることもあります）。そのため表示する語をスコアリングし、**作った単語を実際に訳す語**だけを選びます：
  - 単語と完全一致する英訳（または冠詞を除いて一致する「the Goat」）を最優先します
  - スクレイプされた「Wikipedia definition」は記事本文であり訳ではないため無視します
  - 助数詞・複合形（五つ）よりも漢字表記（五）、かな読み（ゴート）よりも漢字表記を優先します
  - 単数形と複数形の両方に対応します：Jisho は語形を並べて返すため（卵なら `["eggs", "egg", "spawn", "roe"]`）、語形をまとめて比較し、入力した形を先頭に表示します
  - 該当する訳が無い場合は、無関係な語を出さず「訳なし」と表示します

- 検索結果は**キャッシュ**され、同じ単語を2回以上取得することはありません
- 単語を変更すると表示も更新され、遅れて届いた古い単語の結果は無視されます
- 該当なし・通信失敗はその場で表示され、これもキャッシュされるため、処理が止まったり繰り返し通信したりしません
- **Webエクスポートの制約**：jisho.orgは `Access-Control-Allow-Origin` ヘッダーを返さないため、ブラウザがリクエストをブロックします。**同梱 glossary は Web 版でも動作します**（ローカルファイルなので）ので短い単語は翻訳されます。使えないのは Jisho のフォールバックだけで、その旨が表示されます。ブラウザでフォールバックも使いたい場合は CORS プロキシが必要です

### スロットの回転
- 単語で使用したスロットのみが回転します。使用した★ACTIVEのカードは消費され、リールが回転してNEXTのカードがACTIVEになります
- ワークベンチに置いたカードが必ず消費されます（使用した共有札が手札に勝手に差し替えられることはありません）ので、使用したリールは必ず回転します
- ステージクリア時は3列すべてのリールが回転し、新しい敵の共有札が表示されます

### 昼/夜フェーズ
ゲームは各ターンごとに昼と夜のフェーズを交互に切り替えます：

**昼フェーズ**: 被ダメージなし
**夜フェーズ**: ターン開始時に、すべてのスロットの次のカードのダメージ合計分のダメージを自分が受ける

### カードの色と倍率
各カードには色属性があります（赤、青、緑、黄、またはワイルドカード用の金）。ダメージ倍率は単語内で一緒に使った**赤いカードのみ**に適用されます：

- **赤2枚**: 2倍
- **赤3枚**: 4倍
- **赤4枚**: 8倍
- 計算式: 2^(n-1) （nは赤カードの枚数）

青・緑・黄の同色複数枚はダメージ倍率になりません（それぞれの色は特性を発動させます。参照: カラー特性）。

単語の倍率は以下に適用されます：
- 単語で与えるダメージ

夜フェーズの自己ダメージは、より大きな色倍率を使用します：
- **同色2枚**: 10倍のダメージ
- **同色3枚**: 100倍のダメージ
- 計算式: 10^(n-1) （nは同色の次のスロットカードの数）

### カラー特性
有効な単語で使ったカードの色が特性を発動します（共有札も同様にカウントされます）：

- **赤 — 攻撃倍率**: 敵へのダメージはベース合計基準で `base × 2^(赤枚数-1)`（赤1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍）。追加ボーナスは乗りません。
- **青 — シールド**: シールド獲得量はベース合計基準で `base × 2^(青枚数-1)`（上限なし）。シールドはHPに被害が及ぶ前にダメージを吸収します（夜の自己ダメージ・負の単語ダメージ）。
- **緑 — 回復**: 回復量はベース合計基準で `base × 2^(緑枚数-1)`（最大HPまで）。
- **黄 — 操作ポイント（OP）**: OP はベース合計基準で `base × 2^(黄枚数-1)`（黄1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍）。OPはスコアではなく通貨で、ダメージでは消費されずリセットもされません。**1 OPでワークベンチのカードを左右に1つ移動できます**（ターンは消費しません）。**★スペシャルはそのカードのダメージ数値のOPを支払って発動します**（8ダメージ=8 OP、10ダメージ=10 OP）。OPが足りない場合は発動できません。
- **⟳ 共有リールの回転**: 3つの共有リールそれぞれの下に **`SPIN`** ボタンがあります。押すと**そのリールだけ**が**1段だけ**進み、`→ NEXT` に表示されていたカードが新しい `★ ACTIVE` になります。回転はターン末尾と同じスクロールアニメーションで行われ、残り2つのリールには影響しません。都合の悪いリールだけを引き直せます。OPは実際に回転できたときだけ消費されます。
- **回転は1ターン3回までで、価格は段階的に上がります（1 OP → 10 OP → 100 OP）。** ボタンは毎回価格を読み直し、3回を使い切ると `NO SPINS` と表示されます。リールは手札以外でどの文字が出るかを制御する唯一の手段なので、3回目は通常の1ターンの収益を大きく超える価格になっています。
  - **ACTIVEカードがワークベンチに置かれているリールは回転できません**（単語が勝手に変わってしまうため）。先にカードを戻してください（ボタンが押せない状態になり、ツールチップに理由が表示されます）。
  - 回転はターンを消費せず、3枚一周すると元に戻ります。**ただの無料シャッフルにはできません**。
  - OPは黄カードと **INSIGHT** 報酬から得るため、回転に使うと **★スペシャル** との有限のトレードオフになります。

特性の基準は**プラスのベース合計**です（負の単語では特性値は発生しません）。各特性の適用は1回のみです。

### ワイルドカード
- **「?」カード**は任意の文字を表すことができます
- ダメージは0ですが、難しい単語を完成させるのに役立ちます
- プールには9枚のワイルドカードが含まれ、ランダムな20枚のデッキに入る枚数はゲーム毎に変わります
- 各ワイルドカードは通常のカードと同様に色属性（赤、青、緑、黄）を持っています
- ワイルドカードの色を他の同色カードと合わせることで倍率を上げられます
- 文字は金色で表示され、枠線でその色を確認できます

### ダメージ値
各文字はレア度に基づいてダメージ値を持っています：
- 1ダメージ: E, A, I, O, N, R, T, L, S, U（一般的）
- 2ダメージ: D, G
- 3ダメージ: B, C, M, P
- 4ダメージ: F, H, V, W, Y
- 5ダメージ: K
- 8ダメージ: J, X
- 10ダメージ: Q, Z
- 0ダメージ: ?（ワイルドカード）

### 計算式
ゲーム内の **FORMULAS** ボタンを押すと計算式パネルが開きます。以下の全計算式がコード内の実際の数値付きで表示され、直前に提出した単語の内訳も確認できます。

**敵へのダメージ（プラスのダメージ）**
- `base`（基本ダメージ）= 単語に置いた全カードのダメージ合計（ベース合計）
- `赤倍率` = 2 ^ (赤カード枚数 - 1) → 赤1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍
- `最終ダメージ` = base × 赤倍率。青・緑・黄の同色複数枚はダメージを倍加しません
- **AEGIS（敵）**: 敵のシールドが先にダメージを吸収し、HPに届くのは残った分だけです。なお、その文字を使った単語は吸収後もシールドを追加します
- 敵の残りHPを超えたダメージは切り捨て（次の敵に引き継がれません）

**青のシールド（自分）**
- `シールド` = base × 2 ^ (青カード枚数 - 1) → 青1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍（上限なし）
- `吸収量` = min(シールド, 被ダメージ)。夜の自己ダメージと負の単語ダメージをHPより先に吸収します

**緑の回復（自分）**
- `回復` = base × 2 ^ (緑カード枚数 - 1) → 緑1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍（最大HPまで。ゲーム開始時は50で、IRON WILL報酬で上昇します）

**黄の操作ポイント（OP・自分）**
- `OP` = base × 2 ^ (黄カード枚数 - 1) → 黄1枚=1倍、2枚=2倍、3枚=4倍、4枚=8倍
- 1 OP = ワークベンチのカードを1つ左右に1マス移動。OPは蓄積し、ダメージで消費されません

**カードのコスト — ダメージ数値がそのままコスト（OPで支付）**
- 全カードの `コスト` = カードに印字されたダメージ値
- ★スペシャル（8ダメージ以上のカード）は、そのダメージ値のOPを支払って発動（8ダメージ=8 OP、10ダメージ=10 OP）
- 発動するとそのカードと同じ色の手札がすべて捨てられ、新しいカードを引きます（ターンは消費しません）
- OPが足りない場合は発動が拒否され、カードもOPも消費されません
- **DISCARD & DRAW はワークベンチが空のときしか発動できません。** ランダムに1枚捨てる（= 自分が選んでいないカードを捨てる）ため、ワークベンチに何か置いている間は拒否され、カードがグレーアウトしてツールチップに理由が表示されます。先にワークベンチを空にしてください。拒否時は OP もカードも消費しません。他のスペシャルはワークベンチにカードがあっても発動できます

**夜の自己ダメージ**
- `ペナルティ` = (3スロットのNEXTカードのダメージ合計) × 10 ^ (同色枚数 - 1) → 同色2枚=10倍、3枚=100倍、4枚=1000倍
- NIGHTMARE の値は同色の倍率を掛ける前の**基礎値**に加算されます
- 青のシールドが先に吸収し、残りがHPに適用されます
- **敵を撃破したターンはダメージを受けません**（戦闘が終わったためそのターンの夜のペナルティは発生しません）。プレビューには `NIGHT 0 dmg  (enemy defeated)` と表示されます。この免除はそのターンだけです。次のターンは通常どおりペナルティを受けます

**その他**
- 負の単語では特性値は発生しません（特性はプラスのベース合計を使用）
- 黄: 操作ポイント（OP）を獲得（前述） / ワイルドカード「?」: ダメージ0・任意の文字・色はそのまま
- 敵HP: ステージ1は30、ステージ毎に最大HP+15 / プレイヤーHP0で敗北、10ターンでCOMPLETE

### 勝利戦略のヒント
1. **先を見越す**: スロットの次のカードを見て、将来の被ダメージを予測（計算式の「夜の自己ダメージ」参照）
2. **色のマッチング**: 倍率のために同じ色のカードを使用
3. **スロットの管理**: どのスロットを使用するか検討（使用したスロットは次のカードに回転します）
4. **ワイルドカード**: 難しい文字の組み合わせのためにワイルドカードを残す
5. **HPを守る**: 夜フェーズで大きな被ダメージを受けると敗北します
6. **ステージとカードリセット**: ステージクリア時は手札とスロットが入れ替わるため、とどめを刺す前に大事なカードを使っておきましょう

### 操作方法
- **カードをクリック**: ワークベンチに追加
- **カードをドラッグ**: ワークベンチにドラッグ＆ドロップ
- **ワークベンチのカードをクリック**: ワークベンチから削除
- **手札の★カードを長押し/右クリック**: カードのダメージ数値のOPを支払ってスペシャルを発動
- **CLEAR**: ワークベンチからすべてのカードを削除
- **SUBMIT WORD**: 単語をスコアリングのために提出
- **FORMULAS**: 計算式と直前の単語の内訳の表示/非表示を切り替え
- **OPゲージ**（HPバーの右の金色の枠）: 所持OP・それでできるカード移動回数（`= N MOVES`）・バーを常時表示し、獲得時は数字がポップして `+N OP` が浮かびます。パネルにカーソルを合わせると詳細ルールのツールチップが表示されます

## プロジェクト構成

```
src/            ゲーム本体
  Main.gd/.tscn   シーンと UI の配線
  core/           GameManager.gd（ルール、autoload）、JishoClient.gd（autoload）
  ui/             DraggableCard.gd、WorkbenchDropZone.gd
data/           word_dictionary.json（実行時）、dictionary.txt（フォールバック）、head3000.json
tests/          テスト一式（実行方法は下記）
  fixtures/       Jisho API の固定レスポンス
tools/          build_word_json.py、deck_simulation.py（オフライン補助ツール）
fonts/          同梱の日本語フォント
```

テストシーンは headless で実行します：

```
godot --headless --path . res://tests/_spin_test.tscn
```

古い2つは `SceneTree` スクリプト（シーンではない）なので `--script` を使います：

```
godot --headless --path . --script res://tests/_special_cost_test.gd
```
